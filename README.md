# Fit mommy

App de rutinas de gimnasio para el celular (PWA). Funciona sin internet una vez abierta.

- Pregunta cada semana cuántos días vas a ir (2 a 6) y te dice qué te toca hoy.
- Pierna y glúteo 2 veces por semana, tren superior para tonificar.
- Energía del día: tranquila (6 ejercicios), normal (7) o con energía (8).
- Registra peso, series y repeticiones y sugiere cuándo subir el peso.
- Ejercicios aptos para prótesis de rodilla, con fotos y variantes.

Fotos: [Free Exercise DB](https://github.com/yuhonas/free-exercise-db) (dominio público).

Al cambiar archivos, sube `VERSION` en `sw.js` para que los celulares descarguen la versión nueva.
